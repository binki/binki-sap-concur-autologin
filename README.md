Automatically login to SAP Concur.

The SAP Concur login screen requires clicking a screen for entering your email, choosing to use a password, and entering the password prior to presenting the MFA entry screen. It has short session times, often leaving you logged out even if you specify remember. This clicks through most of those screens for you. As a bonus, it detects pastes on the MFA screen which can be a nice touch on mobile.
